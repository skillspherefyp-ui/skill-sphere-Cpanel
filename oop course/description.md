Master Object-Oriented Programming in C++ and learn how to design clean, reusable, and scalable software the way professional developers do. This course builds directly on C++ fundamentals and takes you deep into the OOP paradigm — from classes and objects all the way to templates, STL, and real-world design principles. Every concept is taught with clear explanations, practical examples, and hands-on programs that solidify your understanding.

What you will learn:
- Review of C++ basics and why OOP was invented
- Defining classes and creating objects with attributes and methods
- Constructors, destructors, and object lifecycle management
- Encapsulation and access specifiers: public, private, and protected
- The this pointer and static members explained with examples
- Operator overloading to extend C++ operators for custom types
- Inheritance: single, multilevel, and multiple inheritance
- Handling ambiguity in multiple inheritance and virtual base classes
- Polymorphism and virtual functions for flexible program design
- Abstract classes and pure virtual functions
- Friend functions and friend classes
- Function and class templates for generic programming
- Exception handling: try, catch, and throw
- Standard Template Library (STL): vectors, maps, stacks, and more
- OOP design principles and complete practice programs

Who this course is for:
1. Students who have completed a C++ fundamentals or ITP course
2. Computer science students studying software engineering or OOP
3. Developers who want to write cleaner, more maintainable C++ code
4. Anyone preparing for data structures, design patterns, or advanced programming

By the end of this course you will be able to:
- Design and implement programs using the full OOP paradigm
- Write reusable code using inheritance, polymorphism, and templates
- Handle errors gracefully using exception handling
- Use the STL to solve problems efficiently with built-in data structures
- Apply OOP design principles to build well-structured, real-world applications
